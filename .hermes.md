## Build Commands
```bash

# Frontend (Next.js)
docker compose build frontend && docker compose up -d frontend

docker compose build control && docker compose up -d control

docker compose up -d --build

make test && make lint && make build && make format
```

## Plane Boundaries (never violate)
1. **Go Real-Time Plane**: autoritative market-data, features, strategy, signal, risk, execution. No synchronous billing/referral/commission/payout.
2. **Python Research Plane**: datasets, backtesting, calibration, ML. Not mandatory per live tick.
3. **NestJS Control Plane**: IAM/MFA/RBAC, subscriptions, billing, licensing, referrals, commissions, payouts, audit.
4. **Next.js Presentation Plane**: renders server-authoritative truth. Never risk/strategy/entitlement/finance authority.
5. **Windows/MQL Edge**: lightweight execution adapters. No primary intelligence or server credentials in EAs.

## Production Safety Rules
Without explicit operator authorization, do NOT:
- Enable live automated trading
- Place or close live broker orders/positions
- Mutate real subscriptions, commissions, wallets or payouts
- Run destructive production migrations
- Rotate production signing keys
- Export production secrets
- Grant database superuser
- Change production DNS
- Publish unsupported performance/profitability claims

## NO-TRADE is a valid first-class result
Never force a trade to meet frequency targets. Do not fabricate live ticks, fills, P&L,
or performance claims. Demo/replay/sandbox data must be unmistakably labeled.

## Definition of Done
Applicable evidence: implementation, migration, backward compatibility, unit/integration/E2E,
golden/parity, replay, load, chaos, security, observability, documentation, backup/restore,
rollback, acceptance criteria. P0 safety/security/financial failures cannot be waived.
