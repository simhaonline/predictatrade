How it works
  • Independent input. The module computes its own astro-timing context from a verified ephemeris and classical rules — fully separate from the price and structure pipeline.
  • Fusion, not replacement. A calibrated layer combines astro context with technical and liquidity evidence. It raises or lowers conviction; it never single-handedly triggers a trade.

How the engine works

Real-time mathematics

Indicators, structure, session and risk metrics are recalculated on every market tick, so the context behind a signal is always current — not a stale snapshot.

Specialist AI agents

Separate agents each score one dimension — momentum, structure, sentiment and timing — then a reconciling layer combines them with explicit, auditable weighting.

Explainable output

Each signal shows which factors contributed and how strongly, so you can inspect the reasoning instead of trusting a single number.

Signal context

Every read combines momentum (trend, volatility and oscillator families), market structure (swings, breakouts and order-flow context), multi-timeframe alignment (scored across minute to daily charts), and session, liquidity and news context.

Risk envelope

Stop & target enforcement

Stop-loss and take-profit are enforced server-side, monitored continuously, and can be closed automatically if they go missing.

Emergency controls

A single halt can close all activity and disconnect execution when something looks wrong.

Hard gates

Spread, slippage, margin, news, session, exposure, reward/risk and time-to-live are checked before any signal is delivered. NO-TRADE is valid.

How we validate

Frozen, versioned data

Dataset provenance and strategy/feature/target/exit/cost versions are frozen before any run.

No leakage

Look-ahead, target leakage and post-outcome filtering are prevented so results can't peek at the future.

Cost-aware simulation

Every run models bid/ask, spread, slippage, commission, latency, carry and missed/partial fills — results reflect real trading cost, not idealised fills.

Walk-forward + out-of-sample

Backtest, walk-forward and locked out-of-sample slices confirm behaviour beyond the data it was tuned on.

Calibrated confidence

Confidence is calibrated against outcomes with sample-size checks — a raw score is never presented as a probability.

Stress & promotion

Monte Carlo/stress, baselines and ablations; promotion only via paper/shadow with drift evidence.
