06 / Platform Architecture

Five planes. One source of truth.

A deliberately separated architecture: the real-time trading plane is never blocked by billing, and the presentation plane never becomes the authority for risk, strategy or finance.

Go Real-Time Trading Plane

Authoritative market-data, feature, strategy, signal, hard-risk, execution-authorization, realtime delivery and reconciliation. No synchronous billing dependency in tick-to-signal processing.

Python Intelligence / Research Plane

Datasets, research, backtesting, walk-forward/OOS, calibration, ML/NLP/vision research and drift validation. Not a mandatory dependency for every live tick.

NestJS SaaS / Control Plane

IAM/MFA/RBAC, tenants, subscriptions, billing/webhooks, entitlements, licensing, devices, MT accounts, referrals, commissions, payouts and audit.

Next.js Presentation Plane

Public site, user portal, admin operations console and the XAUUSD Live Command Center. Renders server-authoritative truth — never recomputes risk, probability or finance.

Windows / MQL Edge

Go Windows Agent + MQL4/MQL5 are lightweight execution adapters and guards. No primary predictive intelligence or private signing credentials live in the EAs.

Finance Ledger-Backed Truth

Subscription, referral, commission and payout truth is exact-decimal, transactional, idempotent, auditable and ledger-backed — isolated from the Go hot path.
