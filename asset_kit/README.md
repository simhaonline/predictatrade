# Predict-A-Trade Logo Asset Kit

Production-ready monochrome logo assets reconstructed from the approved brand
boards and guideline PDF. All SVG files contain fixed vector paths; no live
fonts or embedded raster images are used.

## Included

- Primary vertical logo: black and white reverse, SVG + transparent PNG
- Horizontal logo: black and white reverse, SVG + transparent PNG
- Icon only: bull, five candlesticks, circular flow, and rising arrow
- Wordmark only, plus an additional wordmark-with-tagline lockup
- Filled and supplemental outlined vertical versions
- Dashboard header logo for light and dark surfaces
- Favicons: 16, 32, and 48 px PNG, SVG master, and multi-resolution ICO
- App icons: 64, 128, 256, 512, and 1024 px PNG, plus SVG master
- Visual overview and QA report

## Color use

- Light surfaces: #000000
- Dark surfaces: #FFFFFF
- Background: transparent in every deliverable

## Spacing and proportions

- All masters use fixed viewBox geometry and centered optical alignment.
- Icon-only assets preserve approximately 10% clear space on each side.
- The vertical lockup preserves at least 6.7% outer horizontal clear space.
- The horizontal lockup uses a fixed divider and optically balanced tagline.
- Do not stretch, skew, rotate, recolor, or retype the wordmark.

## Important governance note

The filled versions are the official everyday assets. The outlined version is
included because it was specifically requested, but the source guideline says
the wordmark should not ordinarily be simulated as an outline. Treat the
outlined files as a controlled supplemental treatment and obtain brand approval
before public use.
