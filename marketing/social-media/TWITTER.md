## Twitter/X Thread Strategy

### Weekly Thread Schedule

**Monday:**
> Market outlook thread (week ahead analysis)

**Wednesday:**
> Educational thread (trading concept deep-dive)

**Friday:**
> Week in review thread (transparent results, including losses)

### Thread Best Practices

1. Hook in first tweet (make it compelling)
2. Each tweet adds value (no filler)
3. Use visuals when possible
4. End with CTA (but not pushy)
5. Include disclaimer in final tweet
