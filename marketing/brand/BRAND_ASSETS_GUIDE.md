## Usage Guidelines

### File Formats
- **Social Media:** PNG or JPG (sRGB color profile)
- **Print:** PNG or TIFF (CMYK for print)
- **Web:** WebP or PNG (optimized for web)

### Sizes to Export
| Platform | Profile | Banner/Cover |
|----------|---------|--------------|
| Instagram | 400x400 | 1080x1080, 1080x1920 |
| Facebook | 400x400 | 820x312, 1200x630 |
| Twitter/X | 400x400 | 1500x500, 1200x675 |
| LinkedIn | 400x400 | 1584x396, 1200x627 |
| YouTube | 800x800 | 2560x1440, 1280x720 |

### Color Consistency
Always use the exact hex codes:
- Primary Blue: #1a365d
- Primary Gold: #d4af37
- Light Blue: #3182ce
- Dark Gold: #b8941f

### Text on Images
- Keep text minimal
- Use high contrast (white text on dark, dark text on light)
- Ensure readability at mobile sizes
- Include risk disclaimer when showing trading content

## Notes for AI Generation

### Midjourney Tips
- Use `--ar` for aspect ratio
- Use `--v 6` for latest model
- Use `--style raw` for cleaner results
- Use `--no text` to avoid text in images

### DALL-E Tips
- Specify "no text" in prompt
- Request "professional, clean style"
- Mention exact hex colors
- Specify dimensions

### Stable Diffusion Tips
- Use negative prompts: "text, words, letters, blurry, low quality"
- Use high CFG scale (7-10)
- Use 30-50 steps
- Use appropriate sampler (Euler a, DPM++ 2M)
