# Referral Commission v3

New effective-dated rules are seeded separately from historical rules: STANDARD 10/3/1%, PRO 15/4/2%, ELITE 18/5/2% for L1/L2/L3; L4/L5 receive no new v3 allocation. Multipliers are 100% L1-L3 for the first eligible paid event, 75% L1 only for the second, and 50% L1-L3 thereafter. FREE registration is not a paid event. Commission calculations use `eligible_amount` and Decimal arithmetic; historical ledger rows are not rewritten.
